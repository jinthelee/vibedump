# VibeDump (바이브덤프)

> **바이브 코딩으로 만들어진 웹사이트와 앱을 발견하고, 공유하고, 탐색하는 플랫폼**

VibeDump는 AI 코딩 도구(Claude, Cursor, Gemini 등)와 바이브 코딩을 통해 즉흥적이거나 창의적으로 제작된 웹앱, 1인 개발 클릭커 게임, AI 미니멀 도구, 밈 캔버스, 프로토타입을 한곳에 모아 보여주는 발견형 플랫폼입니다.

## 2. 환경변수 설정 (`.env`)

`.env.example` 파일을 복사하여 `.env` 파일을 생성합니다:

```bash
cp .env.example .env
```

| 환경변수명 | 기본값 | 설명 |
| :--- | :--- | :--- |
| `PORT` | `3000` | 서버 및 앱이 구동될 포트 |
| `ADMIN_SECRET` | `vibedump-admin-2026` | 관리자 콘솔 접근 및 관리자 API 인증 토큰 |
| `DATABASE_PATH` | `./data/vibedump.db` | 영구 저장을 위한 SQLite DB 파일 경로 |
| `APP_URL` | - | 배포 호스팅 URL (AI Studio Cloud Run 자동 주입) |

## 3. 실행 방법

### 개발 환경 실행
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다. (Express 서버가 구동되고 Vite Dev Server 미들웨어가 동시에 마운트됩니다.)

### 프로덕션 빌드 및 실행
```bash
npm run build
npm run start
```

## 4. 데이터베이스 스키마 및 초기화

VibeDump는 Node.js 22 내장 고성능 `node:sqlite`를 사용하여 별도의 C++ 네이티브 컴파일 없이 완전한 파일 기반 영구 저장을 보장합니다.

### 주요 테이블 구성
1. **services**: 서비스 기본 정보, 외부 URL, 한줄 소개, 상세 설명, 대표 분야, 스크린샷, 제작자 표시명, **해시화된 제작자 코드 (`maker_code_hash`)**, **비공개 연락처 (`maker_email`)**, 조회수, 좋아요수, 공개 상태 (`approved`, `pending`, `rejected`, `hidden`)
2. **tags**: 태그명, 정규화된 태그명 (`normalized_name`), 상태
3. **service_tags**: 서비스와 태그 간의 다대다(N:M) 매핑
4. **reviews**: 별점 (1~5점), 후기 본문, 작성자명, 작성일, 관리 상태 (`published`, `hidden`)
5. **reactions**: 반응 종류 (`like`, `fire`, `heart`, `rocket`, `mind_blown`), 클라이언트 익명 식별 토큰 (`UNIQUE(service_id, type, client_token)`)
6. **favorites**: 클라이언트 익명 토큰 기반 찜 데이터 (`UNIQUE(service_id, client_token)`)
7. **reports**: 신고 대상 (`service`, `review`), 신고 사유, 상세 내용, 처리 상태 (`pending`, `resolved`, `dismissed`)
8. **maker_posts**: 제작자 전용 공지, 버전 업데이트, 개발일지
9. **curations**: 에디터 추천 및 "이번 주의 발견" 배지, 한줄 코멘트, 노출 순서
10. **promotions**: 스폰서 광고 슬롯, 노출수(impressions), 클릭수(clicks) 추적

### 초기 시드 데이터
서버 첫 구동 시 `initDatabase()`가 자동으로 호출되어 다음 데이터가 구축됩니다:
- **12개 고정 대표 분야**: AI, 생산성, 비즈니스, 개발, 창작, 게임, 밈, 덕질, 라이프, 학습, 소셜, 발견
- **20개 기본 표준 태그**: AI, 자동화, 생성, 웹앱, 프로토타입, 요약, 분석, 시각화, 대시보드, 협업, 메모, 기록, 관리, 검색, 추천, 공유, 디자인, 글쓰기, 게임, 커뮤니티
- **엄선된 초기 시드 프로젝트 6종** (실제 고해상도 목업 에셋 연동 및 리뷰/공지 포함)
- **"이번 주의 발견" 큐레이션 및 명확히 표기된 `[스폰서]` 광고 슬롯 샘플**

## 6. 보안 점검 결과

1. **공개 API 모델 보호**:
   - `GET /api/services` 및 `GET /api/services/:id`는 `SELECT` 절에서 `maker_email` 및 `maker_code_hash`를 명시적으로 제외하여 일반 방문자에게 노출되지 않습니다. (테스트 검증 완료)
2. **제작자 인증 보안**:
   - 제작자 코드는 원문으로 DB에 저장되지 않으며, `crypto.createHash('sha256')`를 거친 다이제스트만 저장되어 검증됩니다.
3. **관리자 권한 강제**:
   - 모든 관리자 API는 `x-admin-token` 헤더 또는 `Authorization: Bearer` 토큰을 서버단 미들웨어에서 엄격히 검증하며, 미인증 요청은 `401 Unauthorized`로 차단됩니다.
4. **외부 URL 및 입력값 위생 처리**:
   - 외부 링크는 `http:` 및 `https:` 프로토콜만 허용하며, 악성 스키마(`javascript:`, `file:`)를 차단합니다.
   - 외부 사이트 이동 전 사용자에게 주의를 환기하는 "외부 사이트 이동 안내 모달"을 제공합니다.
5. **요청 남용 방지**:
   - 서비스 등록, 후기 작성, 신고 요청에 IP 기반 윈도우 레이트 리밋이 적용되어 있습니다.

## 7. 기존 VibeDump와의 기능·구조 차이 요약

| 비교 항목 | 기존 일반 디렉토리 / 프로토타입 | VibeDump (본 구현체) |
| :--- | :--- | :--- |
| **아키텍처** | 클라이언트 상태만 존재하거나 모의 데이터에 의존 | Express 백엔드 + SQLite 영구 DB + React SPA 완전 통합 |
| **보안 모델** | 관리자 메뉴만 숨기거나 이메일/코드가 API 응답에 노출 | 서버단 SHA-256 해시 검증, 관리자 토큰 인가, 민감 정보 API 완전 격리 |
| **태그 통계** | 단순 문자열 저장 또는 입력 횟수 기반 집계 | **서로 다른 공개 서비스 수 기반 집계**, 7일 급상승 추이 분석 |
| **제작자 권한** | 회원가입 강제 또는 권한 확인 불가 | 무작위 제작자 코드(Maker Code) 기반 가벼우면서도 안전한 권한 증명 |
| **수익화/스폰서** | 일반 랭킹을 임의 조작하거나 미표시 | 스폰서 배지 명확한 분리 표기, 노출수·클릭수 투명 집계 |
| **디자인 헌법** | 보라색 그라데이션, 알약형 뱃지 남발 (AI Slop) | **Zero-Pill 철학 준수**, 타이포그래피 구분선(`·`), 정제된 60-30-10 팔레트 |
